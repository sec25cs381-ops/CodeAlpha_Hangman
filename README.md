# Hangman Game

A simple text-based Hangman game written in Python, created for my CodeAlpha Python Programming Internship (Task 1).

## About

The computer picks a random word, and the player guesses it one letter at a time. The player can make up to 6 wrong guesses before the game is over.

## Features

- Random word chosen from 5 predefined words
- Maximum of 6 incorrect guesses
- Shows word progress with blanks
- Displays guessed letters and remaining wrong guesses
- Input validation for numbers, symbols, multiple characters, and repeated letters
- Option to play again

## Concepts Used

random module, while loops, if-else, strings, lists, sets, functions

## How to Run

1. Install Python 3 from [python.org](https://www.python.org).
2. Download hangman.py.
3. Run in a terminal: python hangman.py (or open it in IDLE and press F5).
